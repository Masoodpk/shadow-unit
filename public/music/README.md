# Your own music (optional)

Drop licensed tracks here and the game plays them instead of its built-in procedural score:

- `menu.mp3` — main menu, title and stage select
- `frostline.mp3` — the Frostline (office) stage

Use music you have the rights to (your own, royalty-free with a licence that allows games, or bought).
The files are looped, so tracks that loop cleanly sound best.
